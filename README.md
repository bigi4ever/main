# 🎮 Game Forge: מחולל משחקים אוטומטי

תוכנה שמחליטה לבד איזה משחק לבנות, לפי הז'אנרים הפופולריים היום, ומייצרת משחק דפדפן שלם ומוכן לשחק (קובץ HTML אחד, בלי תלויות, עובד במחשב ובנייד).

## איך היא מחליטה

1. **ז'אנר**: לכל ז'אנר יש ציון פופולריות (`src/trends.js`). הבחירה אקראית אבל משוקללת: ציון גבוה יותר נותן סיכוי גבוה יותר (הציון בריבוע). ז'אנר שכבר נוצר מקבל קנס, כדי שהמשחקים יהיו מגוונים.
2. **נושא**: אחד מ-8 נושאים (חלל, ג'ונגל, אוקיינוס, ממתקים, מפחיד, פנטזיה, רובוטים, חווה). התוכנה נמנעת מצירופים שכבר נוצרו.
3. **קושי ופרמטרים**: מהירויות, קצב אויבים, גודל לוח וכו', לפי רמת קושי שנבחרת.
4. **שם והוראות**: שם בעברית שנבנה מהנושא, והוראות משחק.

| ז'אנר | ציון | מה זה |
|---|---|---|
| `blockpuzzle` | 95 | גרירת צורות ללוח 8×8 וניקוי שורות ועמודות, עם קומבו |
| `survivors` | 90 | הישרדות מול גלי אויבים, ירי אוטומטי, שדרוגים בכל שלב, בוסים |
| `match3` | 89 | מחליפים פריטים צמודים: 4 ברצף יוצרים פס, 5 יוצרים פצצת צבע. יעד ניקוד ומהלכים מוגבלים |
| `arrows` | 87 | מוציאים חצים מהלוח בסדר הנכון. כל לוח פתיר בוודאות (נבנה בסדר הפוך לפתרון) |
| `merge` | 86 | הנחת פריטים: 3 זהים מתמזגים לפריט הבא, עם שרשראות |
| `idle` | 80 | קליקר עם מחוללים, הכפלות, לידה מחדש ורווחים בזמן היעדרות |
| `runner` | 72 | ריצה אינסופית עם קפיצה כפולה, מכשולים ומטבעות |

## שימוש

```bash
node src/cli.js                    # מחליט לבד ובונה משחק אחד
node src/cli.js --count 5          # 5 משחקים שונים
node src/cli.js --trends           # דירוג הז'אנרים וסיכויי הבחירה
node src/cli.js --genre runner --theme space --difficulty hard --seed 42
```

המשחקים נשמרים ב-`games/<slug>/index.html`, והגלריה של כל המשחקים נמצאת ב-`games/index.html`. אותו `seed` תמיד ייצר את אותו משחק.

## טרנדים בזמן אמת

```bash
npm install                                  # פעם אחת: מתקין את ה-SDK של Claude
export ANTHROPIC_API_KEY=sk-ant-...          # או: ant auth login
node src/cli.js --refresh-trends             # מחקר עכשיו + הצגת הדירוג
node src/cli.js --live --count 3             # מרענן אם המחקר ישן מ-7 ימים, ואז בונה
```

מה קורה מאחורי הקלעים (`src/live-trends.js`):
1. **מחקר:** Claude (`claude-opus-5-5`) מחפש ברשת נתונים מהחודשים האחרונים: דוחות Sensor Tower ו-AppMagic, טבלאות ההורדות בחנויות, טרנדים ב-Steam ופורטלים כמו Poki ו-CrazyGames. התוצאה היא דוח עם מקורות.
2. **דירוג:** קריאה שנייה ממירה את הדוח לציון 0-100, מגמה (עולה/יציב/יורד) ונימוק לכל ז'אנר, בפורמט JSON קבוע. היא גם מציעה עד 5 ז'אנרים חמים שעוד אין להם תבנית.
3. התוצאה נשמרת ב-`trends.live.json` ומשפיעה מיד על הבחירה. `--trends` מציג את הציונים, המגמות, הרעיונות החדשים והמקורות.

עלות: כל רענון הוא כמה קריאות API עם חיפושים, בדרך כלל סנטים בודדים עד עשרות סנטים. לכן `--live` מרענן רק פעם בשבוע.
בלי מפתח או בלי רשת התוכנה ממשיכה לעבוד עם הציונים הקיימים.

סדר העדיפויות של הציונים: ציון בסיס (`src/trends.js`) ← מחקר חי (`trends.live.json`) ← דריסה ידנית (`trends.override.json`):

```json
{ "runner": 95, "idle": 60 }
```

## 💡 AI שממציא מכניקות חדשות

```bash
node src/cli.js --invent                          # ה-AI ממציא מכניקה חדשה לגמרי
node src/cli.js --invent --idea "משהו עם כבידה"   # עם כיוון שלכם
node src/cli.js --inventions                      # הספרייה של ההמצאות
```

צינור העבודה (`src/invent.js`), כמו צוות קטן של מעצב, מתכנת ובודק:
1. **עיצוב:** Claude מקבל את רשימת הז'אנרים הקיימים, ההמצאות הקודמות והז'אנרים החמים מהמחקר החי. הוא מעלה לפחות 5 רעיונות, פוסל את מה שקרוב מדי לקיים או מסובך מדי, ומחזיר מסמך עיצוב: חוקים, חדשנות, הוראות, שמות ופרמטרים.
2. **קוד:** Claude כותב `game.js` מול ה-API של זמן הריצה (`src/templates/RUNTIME.md`, עם תבנית לדוגמה).
3. **בדיקה ותיקון:** בדיקה סטטית (תחביר, התנגשות שמות) ומשחק אקראי בדפדפן אמיתי (`src/validate.js`). השגיאות חוזרות ל-Claude, עד 3 סבבי תיקון.
4. **סקירת קוד:** Claude בודק את הקוד מול העיצוב: האם אפשר להפסיד, האם הניקוד עולה, האם הקושי עולה, והאם המשחק מתאים לנייד. אם הסקירה שינתה קוד, הוא נבדק שוב. אם התיקון שבר משהו, נשארים עם הגרסה שעברה.
5. **ספרייה:** ההמצאה נשמרת ב-`src/inventions/<id>/` ונבנה ממנה משחק. מכאן המחולל יכול לבחור בה עם כל נושא ורמת קושי. הציון שלה מוגבל ל-85, כי אין לה עדיין נתוני שוק.

דורש מפתח API ו-Playwright לבדיקה בדפדפן. בלי Playwright מתבצעת רק בדיקה סטטית. עלות: המצאה אחת היא כמה קריאות למודל החזק עם קוד ארוך, בערך דולר עד שניים. טיוטות שנכשלו נשמרות ב-`.inventions-failed/` לבדיקה.

## מבנה

```
src/cli.js                 שורת הפקודה
src/forge.js               הליבה: בחירה, פרמטרים, שמות, בנייה, גלריה
src/trends.js              ז'אנרים וציוני בסיס
src/live-trends.js         מחקר טרנדים חי עם Claude + חיפוש ברשת
src/invent.js              ממציא מכניקות: עיצוב, קוד, בדיקה, סקירה, שמירה
src/validate.js            בדיקה סטטית + משחק אקראי בדפדפן
src/inventions/            ספריית ההמצאות של ה-AI
src/templates/RUNTIME.md   תיעוד ה-API של זמן הריצה (גם בשביל ה-AI)
src/themes.js              נושאים: צבעים, אימוג'י, מילים
src/templates/base.html    זמן ריצה משותף (לולאה, קלט, צלילים, אפקטים, שיאים)
src/templates/*.game.js    לוגיקת כל ז'אנר
test/live-trends.test.js   בדיקת המחקר החי עם לקוח מדומה
test/invent.test.js        בדיקת צינור ההמצאה עם לקוח מדומה
test/logic.js              בודק שכל לוח חצים פתיר ומריץ בוט Match-3
test/smoke.js              בודק שכל ז'אנר נטען ורץ בדפדפן בלי שגיאות (Playwright)
```

## הוספת ז'אנר חדש

1. כותבים `src/templates/<name>.game.js` לפי `src/templates/RUNTIME.md`, שמגדיר `const game = { reset, update(dt), draw, down/move/up/key }`. את `gameOver(score)` קוראים בסוף משחק.
2. מוסיפים רשומה ל-`GENRES` ב-`src/trends.js`.
3. מוסיפים פרמטרים ב-`paramsFor`, שמות ב-`titleFor` והוראות ב-`howtoFor` ב-`src/forge.js`.
