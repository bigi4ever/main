# 🎮 Game Forge: מחולל משחקים אוטומטי

תוכנה שמחליטה לבד איזה משחק לבנות, לפי הז'אנרים הפופולריים היום, ומייצרת משחק דפדפן שלם ומוכן לשחק (קובץ HTML אחד, בלי תלויות, עובד במחשב ובנייד).

## איך היא מחליטה

1. **ז'אנר**: לכל ז'אנר יש ציון פופולריות (`src/trends.js`). הבחירה אקראית אבל משוקללת: ציון גבוה יותר נותן סיכוי גבוה יותר (הציון בריבוע). ז'אנר שכבר נוצר מקבל קנס, כדי שהמשחקים יהיו מגוונים.
2. **נושא**: אחד מ-8 נושאים (חלל, ג'ונגל, אוקיינוס, ממתקים, מפחיד, פנטזיה, רובוטים, חווה). התוכנה נמנעת מצירופים שכבר נוצרו.
3. **קושי ופרמטרים**: מהירויות, קצב אויבים, גודל לוח וכו', לפי רמת קושי שנבחרת.
4. **שם והוראות**: שם בעברית שנבנה מהנושא, והוראות משחק.

| ז'אנר | ציון | מה זה |
|---|---|---|
| `survivors` | 96 | הישרדות מול גלי אויבים, ירי אוטומטי, שדרוגים בכל שלב, בוסים |
| `blockpuzzle` | 93 | גרירת צורות ללוח 8×8 וניקוי שורות ועמודות, עם קומבו |
| `merge` | 88 | הנחת פריטים: 3 זהים מתמזגים לפריט הבא, עם שרשראות |
| `idle` | 84 | קליקר עם מחוללים, הכפלות, לידה מחדש ורווחים בזמן היעדרות |
| `runner` | 79 | ריצה אינסופית עם קפיצה כפולה, מכשולים ומטבעות |

## שימוש

```bash
node src/cli.js                    # מחליט לבד ובונה משחק אחד
node src/cli.js --count 5          # 5 משחקים שונים
node src/cli.js --trends           # דירוג הז'אנרים וסיכויי הבחירה
node src/cli.js --genre runner --theme space --difficulty hard --seed 42
```

המשחקים נשמרים ב-`games/<slug>/index.html`, והגלריה של כל המשחקים נמצאת ב-`games/index.html`. אותו `seed` תמיד ייצר את אותו משחק.

## עדכון הטרנדים

אפשר לערוך את הציונים ב-`src/trends.js`, או ליצור קובץ `trends.override.json` בשורש הפרויקט:

```json
{ "runner": 95, "idle": 60 }
```

## מבנה

```
src/cli.js                 שורת הפקודה
src/forge.js               הליבה: בחירה, פרמטרים, שמות, בנייה, גלריה
src/trends.js              ז'אנרים וציוני פופולריות
src/themes.js              נושאים: צבעים, אימוג'י, מילים
src/templates/base.html    זמן ריצה משותף (לולאה, קלט, צלילים, אפקטים, שיאים)
src/templates/*.game.js    לוגיקת כל ז'אנר
test/smoke.js              בודק שכל ז'אנר נטען ורץ בדפדפן בלי שגיאות (Playwright)
```

## הוספת ז'אנר חדש

1. כותבים `src/templates/<name>.game.js` שמגדיר `const game = { reset, update(dt), draw, down/move/up/key }`. את `gameOver(score)` קוראים בסוף משחק.
2. מוסיפים רשומה ל-`GENRES` ב-`src/trends.js`.
3. מוסיפים פרמטרים ב-`paramsFor`, שמות ב-`titleFor` והוראות ב-`howtoFor` ב-`src/forge.js`.
